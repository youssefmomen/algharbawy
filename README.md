# مؤسسة الغرباوي

موقع مؤسسة الغرباوي لتعليم اللغة العربية، مناسب لكل الأعمار.
مبني بصفحات ثابتة (HTML + CSS + JavaScript) بدون أي خادم، ويعمل مباشرة على GitHub Pages.

## الأقسام الحالية

- 🌱 التأسيس
- 📐 النحو
- 📖 الأدب
- ✨ البلاغة

## كيف أعدّل المحتوى؟

كل المحتوى (اسم الموقع، الأقسام، الدروس) موجود في ملف واحد: **`data.js`**.

- لتغيير اسم الموقع: عدّل قيمة `siteTitle`.
- لإضافة قسم جديد: انسخ قسمًا موجودًا داخل `sections` وغيّر بياناته
  (`id` يجب أن يكون إنجليزيًا قصيرًا بدون مسافات).
- لإضافة درس: أضف عنصرًا جديدًا داخل قائمة `lessons` الخاصة بالقسم.
- نص الدرس عبارة عن فقرات داخل `body`، كل فقرة بين علامتي تنصيص.

بعد الحفظ، ادفع التعديلات إلى GitHub وسيتحدث الموقع تلقائيًا خلال دقيقة.

> إذا غيّرت أقسامًا أو أضفت دروسًا، نفّذ أيضًا:
> `python3 tools/build-meta.py`
> فهو يحدّث `assets/data/meta.js` (الملف الخفيف الذي تقرأه الصفحة الرئيسية).

## بنية الملفات

| الملف | دوره |
|---|---|
| `index.html` | الصفحة الرئيسية (بطاقات الأقسام) |
| `section.html` | صفحة القسم (قائمة الدروس) |
| `lesson.html` | صفحة الدرس |
| `data.js` | **كل المحتوى، هذا ما تعدّله** |
| `assets/data/meta.js` | نسخة خفيفة مولّدة للصفحة الرئيسية (لا تعدّلها يدويًا) |
| `assets/firebase-loader.js` | تحميل Firebase عند الحاجة فقط (لا يحتاج تعديل) |
| `assets/app.js` | منطق العرض (لا يحتاج تعديل) |
| `assets/style.css` | الألوان (الذهبي والأسود) والتنسيق والحركات |
| `firestore.rules` | قواعد حماية قاعدة البيانات (تُنسخ إلى Firebase Console) |

## النشر

الموقع منشور عبر GitHub Pages من الفرع `main`.
رابط الموقع تجده في إعدادات المستودع: Settings ← Pages.

## قواعد حماية قاعدة البيانات (Firestore)

الملف `firestore.rules` يحتوي القواعد المطلوبة. لتفعيلها:

1. افتح [Firebase Console](https://console.firebase.google.com/) ← مشروع `algharbawy`.
2. من القائمة: **Firestore Database** ← تبويب **Rules**.
3. انسخ محتوى `firestore.rules` كاملًا والصقه مكان الموجود ثم اضغط **Publish**.
4. أنشئ وثيقة المدير مرة واحدة فقط:
   - من **Authentication** انسخ **UID** الخاص بحساب المدير.
   - من **Firestore Database** أنشئ مجموعة اسمها `admins` وأضف فيها وثيقة معرّفها (Document ID) هو ذلك الـ UID (أي حقل داخلها يكفي، مثل `role: "owner"`).

بهذا يصبح تحديد المدير من قاعدة البيانات نفسها، ولا يظهر بريد المدير في كود الموقع.
